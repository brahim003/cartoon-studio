# Environment assets (Kenney, CC0)
Packs: castle-kit (76), retro-fantasy-kit (105), pirate-kit (72), mini-forest (22), nature-kit (329), survival-kit (80), food-kit (200), factory-kit (143), retro-textures-fantasy (textures only).
All models are .glb in assets/kenney/<pack>/. Full list: assets/catalog.json. License: CC0 (License.txt in each pack).
Use from three.js: GLTFLoader.loadAsync('/assets/kenney/<pack>/<name>.glb'). Models are small: scale about x3.
Test scene: env/test.html (serve /root/shorts/env with python3 -m http.server 8124, shot via env/shot.mjs).
Characters: rig/ (character-skill-build, MIT): SVG+GSAP, to be placed in the 3D scene as billboards.
